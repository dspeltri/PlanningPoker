Usage Guidelines

Do's, don'ts, and notes for consistent implementation

Colour Usage

✓
DoUse navy (#0a1628 or #262836) as the primary page background for all dark-mode surfaces.
✓
DoUse teal (#007585) only for interactive elements: primary buttons, active states, focus rings, and accent rules. Use teal-light (#29b0c3) for data callouts, stat values, and eyebrow text.
✕
Don'tUse raw rgba(255,255,255,0.04) or any alpha below 0.07 for fills — these become invisible when exported via html2canvas to PPTX.
✕
Don'tIntroduce new brand colours outside the palette. Use module accent colours (teal family, violet, amber, red) for data differentiation only.

Typography

✓
DoUse font-weight: 800 and letter-spacing: -0.03em only for hero/display headings. Section headings use 700 / -0.02em.
✓
DoUse Inter throughout. Body text: 14–15px, lh 1.65–1.75. Caption/metadata: 11–12px. Never go below 10px for rendered text.
✕
Don'tUse positive letter-spacing on body copy. Reserve tracking (+0.05em to +0.12em) for eyebrow labels and uppercase utility text only.

Components

✓
DoUse the teal top-border card pattern (border-top: 3px solid {accent}) to differentiate module cards. One accent per card.
✓
DoKeep icon boxes at 40×40px with border-radius: 10px and background: {accent}30 (18% opacity).
✕
Don'tUse border-radius: 999px (pill shapes) for structural elements in PPT-export contexts — use sharp corners or low radii instead. Pills are safe in the live web app.
ℹ
PPT ExportAll slide content must use inline styles (no Tailwind classes). Avoid borderRadius:999, borderRadius:'50%' on visible fills, negative bottom offsets inside overflow:hidden, and any opacity below 0.07.

Interaction & Motion

✓
DoUse transition: all 0.15s for hover colour changes and transition: all 0.2s for transform/scale states. Keep animations under 300ms.
✓
DoUse hover:scale-105 sparingly — only on interactive node cards in the site map. Cards use background opacity change on hover instead of transform.
✕
Don'tAnimate layout-affecting properties (width, height, padding). Animate opacity, background, color, transform only.
